## ขั้นตอน
1. VM Windows 10/11 ใหม่ ไม่มี Node/Git/Visual Studio, ติดตั้งแค่ Windows Update ล่าสุด
2. คัดลอก Setup.exe เข้า VM แล้วเทียบ SHA-256 ให้ตรงค่าข้างบน
3. ติดตั้ง: บันทึกว่ามีเตือน SmartScreen/Defender ไหม, ติดตั้งสำเร็จไหม, มีทางลัดไหม
4. เปิดโปรแกรมครั้งแรก: ไม่ crash, ไม่ขึ้น error เกี่ยวกับไฟล์ที่ขาด
5. เปิดใช้งาน/ผูกบัญชี (flow device authorization ผ่านเบราว์เซอร์): ได้รหัส → อนุมัติบนเว็บ → Desktop ได้สิทธิ์
6. เว็บแคม: อนุญาตกล้อง, เห็นภาพสด, นับถอยหลัง, ถ่าย, ถ่ายใหม่/ยืนยัน
7. จัดองค์ประกอบภาพ → Simulate print → ตรวจว่าสถานะขึ้นเป็น simulated (ไม่ใช่ submitted จริง)
8. ปิดแล้วเปิดโปรแกรมใหม่: งานและคลังภาพยังอยู่
9. ปิดอินเทอร์เน็ต แล้วเปิดโปรแกรม: ใช้งานแบบออฟไลน์ตามสิทธิ์ที่ออกแบบไว้ได้ไหม
10. อัปโหลดรูปขึ้นคลาวด์ → รับลิงก์แชร์ → เปิดบนมือถือ (ต้องมี R2/สตอเรจที่เข้าถึงได้ ถ้าใช้ S3 mock ในเครื่อง ผลไม่พิสูจน์ R2 จริง)
11. ยกเลิกการเปิดใช้งาน (deactivate) แล้วตรวจว่าเครื่องหลุดจากสิทธิ์
12. ถอนการติดตั้ง: ไม่เหลือโปรเซส/ทางลัด

## สิ่งที่ต้องบันทึกในรายงาน
เวอร์ชัน Windows, เวอร์ชันตัวติดตั้ง + SHA-256, ผลแต่ละข้อ (ผ่าน/ไม่ผ่าน/ข้าม พร้อมเหตุผล), ภาพหน้าจอเมื่อเกิดข้อผิดพลาด, ข้อความเตือนความปลอดภัยของ Windows

## ยังไม่ครอบคลุม
กล้อง/เครื่องพิมพ์จริง, Safari/มือถือจริง, การอัปเดตอัตโนมัติ, ตัวติดตั้งที่ลงนามแล้ว
