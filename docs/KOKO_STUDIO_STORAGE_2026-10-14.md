# งานพื้นที่ว่างก่อนถ่าย — 14 ตุลาคม 2026

ทำส่วนตรวจพื้นที่ว่างที่พักไว้ในระยะ 2 จนเชื่อม Main และ UI ครบแล้ว และสร้าง **Windows staging candidate 0.1.29** สำเร็จ งานนี้ยังไม่ใช่การผ่านเกณฑ์ระยะ 2 ทั้งหมด: ยังไม่ได้ทดสอบแอปที่ติดตั้งจริง กล้อง เครื่องพิมพ์ หรือการใช้งานต่อเนื่อง

## พฤติกรรมที่เพิ่ม

- หน้าสตูดิโอและโหมดแขกรับพื้นที่ว่างจาก Main จริง แสดงหน่วย MiB/GiB พร้อมปุ่ม **ตรวจพื้นที่ใหม่**; หน้าแรกและ Settings แสดงข้อมูลเดียวกัน
- หยุดเริ่มรอบใหม่เมื่อทราบว่าพื้นที่ต่ำกว่า **256 MiB** รวมโหมดภาพตัวอย่างและวิดีโอ; Main ตรวจพื้นที่ใหม่ก่อนสร้างรายการรอบถ่ายและออก capture grant จึงไม่อาศัย UI snapshot เพียงอย่างเดียว
- 256 MiB เป็นเกณฑ์ขั้นต่ำสำหรับเริ่มรอบ ไม่ได้จองพื้นที่หรือรับประกันว่าถ่ายวิดีโอ/ทั้งงานได้ครบ การเขียนที่ล้มเหลวระหว่างรอบยังใช้เส้นทางจัดการข้อผิดพลาดเดิม
- ถ้าอ่านพื้นที่ไม่ได้ แสดงสถานะไม่ทราบและคำแนะนำตรวจไดรฟ์ โดยไม่ตีความเป็นศูนย์; Main ยังตรวจโฟลเดอร์และดัชนีก่อนเริ่ม และการบันทึกยังส่งข้อผิดพลาดจริงกลับมา
- ตรวจใหม่เมื่อเปลี่ยนหน้า กลับมาโฟกัสแอป จบรอบ หรือกดปุ่มตรวจใหม่ ทำให้กลับมาเริ่มรอบได้หลังเพิ่มพื้นที่
- แสดงคำแนะนำภาษาไทยสำหรับกรณีพื้นที่ต่ำจาก Main และดิสก์เต็มระหว่างบันทึก; ภาพที่บันทึกสำเร็จแล้วคงอยู่ในคลัง

## วิธีสำรองและทดสอบ candidate

1. ปิด KOKO Studio Staging ให้หมดก่อนสำรอง คัดลอก **ทั้งโฟลเดอร์เก็บภาพที่เลือกไว้** และ **`%APPDATA%\KOKO Studio Staging`** ไปยังโฟลเดอร์สำรองที่มีวันที่บนไดรฟ์อีกลูก ทั้งสองส่วนต้องเป็นชุดเวลาเดียวกันเพื่อรักษาความสัมพันธ์รูป/รอบถ่าย/เทมเพลต การสำรองเฉพาะ JPEG ไม่ครอบคลุมประวัติทั้งหมด
2. ติดตั้ง candidate 0.1.29 แล้วเปิดจาก shortcut ตรวจเวอร์ชัน โฟลเดอร์เดิม และ License/บัญชีเดิม โดยไม่ตั้ง environment ใน terminal
3. เปิดหน้าแรก Settings สตูดิโอ และโหมดแขก ตรวจว่าพื้นที่ว่างแสดงและกดตรวจใหม่ได้ ทดลองภาพตัวอย่างก่อนใช้งานกล้องจริง
4. ทดสอบพื้นที่ต่ำ/เต็มเฉพาะดิสก์เสมือนหรือ volume ทดสอบที่ไม่มีข้อมูลสำคัญ ห้ามเติมไดรฟ์ระบบหรือไดรฟ์ภาพจริงเพื่อทดสอบ ต้องไม่เริ่มรอบเมื่อทราบว่าพื้นที่ต่ำกว่า 256 MiB และกลับมาเริ่มได้หลังเพิ่มพื้นที่และกดตรวจใหม่
5. ปิดเปิดแอป ตรวจรูปที่บันทึกแล้วและสถานะบัญชี/License; ทำรายการเปิดใหม่ 10 รอบและเครือข่ายหลุดตามแผนระยะ 1 ซึ่งยังไม่มีหลักฐานบน candidate นี้
6. หากต้องกู้คืน ให้ปิดแอป เก็บสำเนาสถานะปัจจุบันไว้อีกชุดก่อน แล้วคืนโฟลเดอร์ภาพและ app data จาก backup ชุดเดียวกันมายังตำแหน่งเดิมบนเครื่องเดิม เปิดตรวจรูปและประวัติ โดยไม่ลบ backup จนตรวจครบ การคืน License บนเครื่องอื่นอาจไม่ผ่านการผูกอุปกรณ์
7. 0.1.28 ยังมี installer สำรอง แต่ยังไม่ได้ทดสอบ downgrade/restore จริง ห้ามถือว่าการรัน installer รุ่นเก่าจะกู้ข้อมูลให้เอง

คู่มือนี้เป็นขั้นตอนทดสอบและสำรองด้วยตนเอง ยังไม่ได้เพิ่มปุ่ม backup/restore ในแอปหรือยืนยันผลกู้คืนบนเครื่องจริง

## งานถัดไปตามแผน

- ติดตั้ง/อัปเกรด 0.1.29 และเก็บหลักฐาน UI/IPC จริง รวม License หลังเปิดใหม่ และพื้นที่ว่างหลังเปลี่ยนไดรฟ์/กู้พื้นที่
- ตรวจกรณีแอปถูกหยุดระหว่างบันทึกจริงบนข้อมูลทดสอบ และช่องว่างระหว่างการบันทึกรูปกับการอัปเดตรายการรอบถ่าย; รอบนี้ทดสอบ ENOSPC แต่ยังไม่ได้จำลองการ kill process ทุกจังหวะ
