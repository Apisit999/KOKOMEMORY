## ลำดับงานต่อ

1. เจ้าของดูหน้าที่ทำเสร็จ แล้วแก้ตามที่ไม่ชอบ (วิธีเปิดเดโม: เปิด emulator + `npm run studio:dev` โดยส่งเฉพาะตัวแปร R2 ของ bucket ส่วนตัวจาก `.env.staging` แล้วอัปโหลดรูปตัวอย่างด้วย Desktop client)
2. กำหนดแผน/ราคา/อายุการเก็บรูป และเลือกเพิ่ม PIN, zip, แบรนด์บนหน้าแขก
3. ปรับหน้าสาธารณะทั้งเว็บให้เข้าแนวเดียวกัน (หน้าแรก, บริการ, จอง, 3D) และตัดสินใจเรื่องฟอนต์ไทย
4. commit งาน Desktop แล้วทดสอบตัวติดตั้งบนเครื่อง Windows สะอาด
5. ออกแบบตู้: เริ่มจากมินิพีซี Windows + เว็บแคมคุณภาพดี + ไฟ ไม่ออกแบบบอร์ดเอง ค่อยเพิ่มทะเบียนตู้และแดชบอร์ดภายหลัง
6. **ก่อนเปิดจริงเท่านั้น:** deploy ตาม `deploy/hostinger/README.md` (ต้องขอ SSH key ชั่วคราวใหม่จากเจ้าของและได้รับอนุญาตก่อน), หมุน key ของ staging ที่เคยหลุดในแชต และเปลี่ยนรหัสผ่านที่เคยวางในแชต, ตัดสินใจเรื่อง code signing, แยก R2 และ key ของ production
